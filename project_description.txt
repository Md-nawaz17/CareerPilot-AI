CareerPilot AI

CareerPilot AI is a modern, production-style AI-powered resume analyzer and career assistant built to help job seekers improve their visibility to recruiters and applicant tracking systems. The platform allows users to upload or paste their resume and receive a detailed ATS-style analysis, including an overall score, a breakdown of strengths and weaknesses, and actionable recommendations for improvement. Users can also compare their resume against a target job description to receive a match percentage, missing-skill insights, recruiter-style feedback, and keyword alignment suggestions.

The project now includes a fully integrated AI-powered cover-letter generation flow that uses an NVIDIA-compatible OpenAI-style client when configured, with graceful fallback to existing providers and local generation logic. The backend analysis engine evaluates resume structure, contact details, formatting quality, action verbs, measurable achievements, skill alignment, and project awareness, while the frontend delivers a polished SaaS-style experience with responsive interactions and a professional interface.

Key Features:
- Resume upload and parsing from PDF, DOCX, and text files
- ATS readiness scoring with detailed feedback
- Job description matching and compatibility analysis
- Highlighting of missing skills and keyword gaps
- AI-generated cover letter support using NVIDIA-compatible inference
- Recruiter-style suggestions and improvement recommendations
- Modern, clean, and responsive dashboard experience
- Backend API tested and verified with Pytest

Tech Stack:
- Frontend: React, TypeScript, Vite, Tailwind CSS, Framer Motion
- Backend: Python, FastAPI, Pydantic
- AI Integration: OpenAI-compatible client with NVIDIA inference support
- Parsing libraries: pdfjs-dist, mammoth
- Testing: Vitest, Pytest

Project Goal:
CareerPilot AI aims to make resume optimization simple, intelligent, and accessible for professionals who want to stand out in competitive job markets. It demonstrates a complete full-stack product experience, strong UI/UX design, practical AI-assisted career tools, and validated backend functionality in a single polished application.
